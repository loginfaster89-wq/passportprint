# React Frontend Deployment

The `react-frontend/` directory contains the new React + Vite frontend for Studio Print.

## Stack
- React + Vite + TypeScript
- Tailwind CSS v4
- Framer Motion animations
- Wouter router
- shadcn/ui components

## Routes
- `/` — Home page (React)
- `/about` — About page (React)
- `/contact` — Contact page (React)
- `/privacy` — Privacy Policy (React)
- `/terms` — Terms of Service (React)
- `/refund` — Refund Policy (React)
- `/passport-photo/` — Passport Photo tool (vanilla HTML)
- `/id-print/` — ID Card Print tool (vanilla HTML)
- `/forms/` — Forms Hub tool (vanilla HTML)

## Build
```bash
cd react-frontend
pnpm install
pnpm build
```

## Features
- Unified brand header on all tool pages matching React app
- Product mockup card in hero section
- Stats, use cases, pricing, FAQ sections
- Mobile responsive with hamburger menu
- SEO meta tags on all pages
